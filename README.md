# Cube Slicer

Geometric subdivision engine — slice a cube with 6 diagonal planes and explore the pieces in 3D.

## Run locally

Requires [Node.js](https://nodejs.org/)

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy

Push to GitHub, then import the repo on [vercel.com](https://vercel.com) and click Deploy.
